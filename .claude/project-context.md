# Project Context for Claude Code AI

## Project Overview
- **Type**: React SPA with MUI
- **Purpose**: Analytics dashboard with multiple charts
- **State Management**: Zustand
- **UI Library**: MUI + MUI X Charts
- **Focus**: Performance, responsive design, minimal spacing

## Key Requirements
- Full-width layouts with minimal padding/margins
- Multiple charts for data visualization
- High performance with optimized re-rendering
- Mobile-first responsive design
- Feature-based folder structure

## Tech Stack
- React 18+
- MUI v6
- MUI X Charts
- Zustand for state management
- Vite for build
- Jest for testing

## File Extension Requirements
- All React components must use `.jsx` extension
- Regular JavaScript files use `.js` extension
- This is required by Vite for proper JSX parsing
